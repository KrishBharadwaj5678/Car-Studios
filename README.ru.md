<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Car-Studios/raw/main/favicon_io/favicon.ico" width="35"/> Car Studio</h1>

<p align="center">
  Car Studio это интерактивное веб-приложение, которое оживляет автомобили с помощью захватывающих 3D-моделей, подробных технических характеристик и технологий дополненной реальности (AR), позволяя вам исследовать и визуализировать автомобили в вашем реальном окружении.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Car-Studios/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| :----------- | :------- |
| 🧭 **Интерактивные 3D-модели** | Исследуйте высокодетализированные 3D-модели автомобилей с возможностью вращения, масштабирования и панорамирования. |
| 📋 **Информация об автомобилях** | Получайте подробные характеристики, особенности и полезную информацию о каждом автомобиле. |
| 🌍 **Дополненная реальность (AR)** | Размещайте автомобили в своём реальном окружении с помощью технологий дополненной реальности. |
| 🎨 **Удобный пользовательский интерфейс** | Наслаждайтесь современным дизайном, высокой производительностью и интуитивно понятной навигацией. |

## <img src="https://github.com/KrishBharadwaj5678/Car-Studios/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонируйте репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/Car-Studios.git
````

### 2️⃣ Перейдите в папку проекта

```bash
cd Car-Studios
```

### 3️⃣ Откройте проект в браузере

Просто откройте файл `index.html` в любом современном браузере.
