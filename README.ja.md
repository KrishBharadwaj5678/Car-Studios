<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Car-Studios/raw/main/favicon_io/favicon.ico" width="35"/> Car Studio</h1>

<p align="center">
  <strong>Car Studio</strong> は、没入感のある3Dモデル、詳細な車両情報、そして拡張現実（AR）を通じて車をリアルに体験できるインタラクティブなWebアプリケーションです。実際の環境で車を表示・確認しながら、さまざまな車両を探索できます。
</p>

![CarStudiosDemo](https://github.com/KrishBharadwaj5678/Car-Studios/raw/main/CarStudiosDemo.png)

<img src="https://github.com/KrishBharadwaj5678/Car-Studios/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/Car-Studios/raw/main/assets/readme/features.gif" width="35"/> 主な機能

| 機能 | 説明 |
| :--- | :--- |
| 🧭 **インタラクティブな3Dモデル** | 高精細な3D車両モデルを自由に回転・ズーム・パンして閲覧できます。 |
| 📋 **車両情報** | 各車両の詳細な仕様や特徴、関連情報を確認できます。 |
| 🌍 **拡張現実（AR）** | AR技術を利用して、実際の環境に車を表示し、リアルなサイズ感で確認できます。 |
| 🎨 **使いやすいユーザーインターフェース** | モダンなデザインとスムーズな操作性で快適に利用できます。 |

## <img src="https://github.com/KrishBharadwaj5678/Car-Studios/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローンする

```bash
git clone https://github.com/KrishBharadwaj5678/Car-Studios.git
```

### 2️⃣ プロジェクトディレクトリへ移動する

```bash
cd Car-Studios
```

### 3️⃣ ブラウザで開く

`index.html` を任意のWebブラウザで開くだけで利用できます。
